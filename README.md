# Pradhan-Mantri-Gram-Sadak-Yojna-PySpark-Project



**PMGSY Mini Project – PySpark Analysis of Indian Rural Road and Bridge Data**

This repository contains code, data, and visualizations for an in-depth analysis of infrastructure projects under various phases of Pradhan Mantri Gram Sadak Yojna (PMGSY), using PySpark and Python data science tools. The project processes and explores a government dataset of 2,292 records (14 columns), detailing road and bridge works sanctioned, completed, and pending across Indian states and districts. Key objectives include data cleaning, computation of completion metrics, and comparative graphical analysis to guide policy and resource allocation.

### Key Features

- **Data Cleaning and Preparation:** Automated workflow using PySpark – reading CSV, inferring schema, deduplication, null handling, column normalization, and metric computation (e.g., completion percentages).
- **Exploratory Analysis:** Regional and scheme-wise assessment of completion, cost utilization, and identification of bottlenecks.
- **Visualizations:** State-level performance charts, cost-expenditure correlation scatter plots, implementation progress (sanctioned vs completed lengths), and aggregate scheme summaries.
- **Scheme-Level Insights:** Comparison of PMGSY phases (I, II, III, RCPLWEA, PM-JANMAN) by completion rates, highlighting mature vs active projects.
- **Actionable Results:** Pinpoints regions and schemes needing monitoring, offers recommendations for operational and strategic focus, and suggests analytical next steps including time-series and predictive modeling.

### Technology Stack

- **PySpark** for distributed data processing and cleaning
- **Matplotlib/Seaborn** for scientific visualizations
- **Pandas** for subsequent analysis and summary statistics

### Use Cases

- Assess development and completion of rural connectivity projects
- Evaluate financial discipline and efficiency across regions
- Enable policymakers and researchers to identify lagging areas for intervention
